# 브랜드 가이드 / Brand Guide — 혜니캘린더 (Hyeni Calendar)

## 1. 브랜드 한 줄 / Brand in one line
**KO —** 부모와 아이가 한 앱에서 함께 쓰는 가족 안전·일정 서비스. 위치와 일정을 "감시"가 아니라 "다정한 연결"로.
**EN —** A family safety-and-schedule app parents and kids share. Location & schedules framed as *warm connection*, not surveillance.

## 2. 이름 / Name
- 표기 / Wordmark: **혜니캘린더** (KO primary) · **Hyeni Calendar** (EN)
- 성격: 마스코트 "혜니"(따뜻한 AI 친구) + 캘린더. 아이에게는 친구 이름, 부모에게는 일정·안전 도구.
- 표기 규칙: 한글 붙여쓰기(혜니캘린더). 로마자에서만 띄어 씀(Hyeni Calendar).

## 3. 마스코트 / Mascot — 혜니
- **정체성:** 분홍 후드를 입은 다정한 3D 캐릭터. 아이의 AI 친구이자 앱의 안내자.
- **역할 / Roles:** 인사(wave)·통화(phone)·응원(cheer)·생각(thinking)·일기(diary)·가족(family) 포즈로 상태를 표현.
- **쓰임:** 히어로 영역, AI 친구 룸, 온보딩, 빈 상태(empty state), 보상 순간. 작은 UI 아이콘 자리에는 쓰지 않음(전용 3D 아이콘 사용).
- **금지 / Don'ts:** 마스코트를 겁주기·경고·처벌 맥락에 쓰지 않기. 표정은 항상 안심·긍정. 비율 왜곡·재채색 금지.

## 4. 로고 / Logo
- 앱 로고(`logo.webp`)는 라운드 스퀘어(radius 10) + 로즈 글로우 그림자. 헤더에서 34px.
- 최소 크기 24px, 여백은 로고 높이의 25% 이상 확보.
- 배경: 밝은 웜 서피스(`#FBF7F4`) 위 사용 기본. 어두운 배경엔 흰 여백판 위에.

## 5. 색 시스템과 의미 / Color & meaning
브랜드는 **4색 + 중립**. 색마다 역할이 고정되어 있습니다. (값은 `tokens`)

| 색 / Color | 값 base | 의미 / Meaning | 쓰임 / Where |
|---|---|---|---|
| 로즈 Rose | `#F76BA6` | 브랜드·부모·아이·애정 | 기본 CTA, 히어로, 로고, 강조 |
| 민트 Mint | `#31C48D` | 안전·정상·성공·선생님 | 안전 뱃지, 길찾기 CTA, 선생님 모드 |
| 라벤더 Lavender | `#A78BFA` | AI·프리미엄·마법 | 혜니 AI, 크레딧, 구독 |
| 골드 Gold | `#FFD76A` | 보상·스티커·성취 | 스티커, 왕관, 칭찬 |
| 위험 Danger | `#E5484D` | SOS·위험구역 | SOS, 경고, 파괴적 액션 |

중립은 웜 잉크/그레이(`#201A1D`→`#C9BFC4`)와 웜 서피스(`#FBF7F4`/`#FFFFFF`). **차가운 순수 회색·블루그레이 사용 금지.**

## 6. 톤 앤 보이스 / Tone & Voice
- **부모 화면 / Parent —** 간결·안심·신뢰. "실시간 추적 중", "지우 · 양호", "방금 업데이트됨". 공포 마케팅 금지.
- **아이 화면 / Child —** 짧고 다정한 반말·친구 말투. "친구랑 놀고 싶어?", "혜니한테 말 걸어볼까?", "같이 놀자고 보내기". 이모지 절제해서 온기만.
- **공통 원칙:** 능동적·따뜻함·짧게. 죄책감·감시 어휘("몰래", "감시") 금지. 존댓말은 부모 대상, 반말은 아이 대상으로 일관.
- **한·영 병기 규칙:** 제품 UI는 한국어 1차. 영어는 개발/핸드오프 문서에서 병기.

## 7. 이미지 스타일 / Imagery
- 부드러운 3D 렌더 캐릭터·아이콘(webp), 파스텔 팔레트, 둥근 형태, 얕은 그림자.
- 사진보다 일러스트/3D. 실제 지도만 예외적으로 지도 톤(민트·크림·로즈 building) 사용.
- 아이콘은 카테고리(학교·태권도·미술·음악·수영 등) 전용 3D 세트로 통일.

## 8. 접근성 / Accessibility
- 본문 대비 AA 이상, 상태색은 색 + 텍스트/아이콘 병행(색맹 대응).
- 최소 터치 44px. 모션 최소화 모드 지원(`data-motion="calm"`).
