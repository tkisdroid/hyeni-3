# 혜니캘린더 — Redesign System v1.0 포트 레이어

이미 잘 구조화된 토큰 시스템 위에 **v1.0의 깔끔·따뜻·프리미엄** 감각을 앱 전체에 한 번에
입히는 드롭인 오버라이드입니다. 컴포넌트를 갈아엎지 않고, 기반 토큰을 재조정하고
프리미티브(입력·버튼·포커스)를 통일해 화면 간 통일성을 끌어올립니다.

포함 파일
- `src/styles/redesign-system.css` — **전역 포트 레이어** (필수, 이거 하나로 앱 전체가 통일)
- `src/components/**` — **낱개 색상까지 정리한 컴포넌트 4종**(아래 "정리된 컴포넌트" 참고)
- `preview.html` — 진짜 `tokens.css` + 이 레이어를 얹어 렌더한 미리보기(참고용, 넣지 않음)
- `reference/tokens.css` — 미리보기가 참조하는 앱 토큰 사본(참고용, 넣지 않음)

---

## 설치 (2분)

1. `src/styles/redesign-system.css` 를 프로젝트의 **같은 경로**(`src/styles/`)에 복사합니다.

2. 아래 **A 또는 B** 한 곳에서 import 합니다. (권장: **A**)

   **A) `src/App.jsx`** 최상단, 기존 `import "./App.css";` **바로 아래**:
   ```js
   import "./App.css";
   import "./styles/redesign-system.css";   // ← 추가
   ```
   App 청크에서 가장 마지막에 로드되어 확실히 우선 적용됩니다.

   **B) `src/main.jsx`** 의 `import './index.css'` **아래**:
   ```js
   import './index.css'
   import './styles/redesign-system.css'    // ← 추가
   ```
   진입 스플래시까지 커버합니다. (파일 내부의 `!important` 락으로 지연 로드되는 `App.css`도 안전하게 이깁니다.)

3. `npm run dev` 로 확인하세요. 잘 됐는지 체크:
   - 앱 배경이 차가운 회색빛 → 따뜻한 크림으로 바뀌었는가
   - 입력창 포커스 링·기본 버튼이 브랜드색인가 (파랑 아님)
   - 카드/리스트 경계선이 회색빛 없이 부드러운가

**되돌리기**: import 한 줄을 지우고 파일을 삭제하면 100% 원상복구됩니다.

## 이 레이어가 자동으로 바꾸는 것 (토큰을 쓰는 모든 화면)

- **차가운 회색 중립 → 따뜻한 크림**: `--bg-subtle` `--bg-muted` 와 `--line-*` 헤어라인.
  카드·리스트·시트·입력 테두리가 동시에 따뜻해집니다.
- **파란 브랜드 → 활성 테마색**: `--primary` 와 포커스 링(`--focus-ring-*`)이 `#0066FF` 파랑에서
  **아이가 고른 테마색**을 따르도록 연결됩니다(아래 "테마 색 일관성" 참고). 파랑은 지도·토요일 등
  "정보색"으로만 남깁니다(토요일 색은 명시 보존).
- **그림자 통일**: `--shadow-sm/md/lg` 를 부드러운 3D 스케일(`--shadow-xs/soft/card`)로 수렴.
- **입력 통일**: 화면마다 다르던 `2px solid #E5E7EB` 류를 따뜻한 1.5px + 테마 포커스 링으로.
- **버튼 촉감**: 눌림(press-scale)과 트랜지션을 전역 통일.
- **앱 셸 배경**: 차가운 `#F8F9FA` → 따뜻한 캔버스 `#FBF7F4`.

런타임 per-child 테마(`--theme-accent*`)는 **건드리지 않습니다** — 아이별 색 선택 그대로 동작.

## 테마 색 일관성 (아이가 색을 바꿀 때) ⭐

아이가 테마 색을 고르면 **버튼 · 캘린더 선택 날짜 · 포커스 링 · "입력 중" 안내 · 강조 칩 · 링크**가
한 번에 그 색으로 통일됩니다. `preview.html` 상단의 색 스와치를 눌러 직접 확인하세요.

**원리** — 앱의 `src/lib/theme.js · applyThemeColor()` 가 아이 색을 CSS 변수
`--theme-accent / -deep / -soft / -line / -text` 로 `:root` 에 주입합니다. 포트 레이어는 다음을
전부 이 변수에 연결해 둡니다:

| 요소 | 연결된 토큰 |
|---|---|
| 기본 버튼(`.hy-btn--primary`, `--hyeni-theme-gradient`) | `--theme-accent` → `--theme-accent-deep` |
| WDS primary 를 쓰는 요소 (`--primary`) | `--theme-accent` |
| 입력 포커스 링 (`--focus-ring-*`) | `--theme-accent` |
| 캘린더 선택일·오늘 링 (`--cal-cell-bg-selected`, `--cal-today-ring`) | `--theme-accent(-soft)` |
| "입력 중"·강조 텍스트·칩 (`.hy-chip--brand/--info`) | `--theme-accent-text/-soft` |

**일부러 안 바뀌는 것 (신호색 고정)** — "안전구역(민트)" · "주의(앰버)" · "SOS·긴급(레드)" ·
"토요일(파랑)" 은 의미가 고정된 색이라 테마가 바뀌어도 유지됩니다. 아이가 색을 바꿔도
**안전 신호를 헷갈리지 않게** 하기 위함이에요.

> 확실하게 "바뀌는 느낌"을 위해 데모(그리고 `.hy-*`·주요 화면)에는
> `transition: background/border/box-shadow/color .35s` 를 넣어 색 전환이 부드럽게 흐릅니다.

## 완전한 v1.0을 위해 화면별로 필요한 작업 (.hy-* 클래스)

토큰만으로는 각 컴포넌트에 **낱개로 박힌 색상**까지는 못 바꿉니다. 다음 값들이 대표적:
- 차가운 회색: `#E5E7EB` `#D1D5DB` `#9CA3AF` `#6B7280` `#374151` `#FAFAFA`
- 파랑 계열: `#3B82F6` `#2563EB` `#4285F4` `#60A5FA`

이런 곳은 `className` 에 유틸리티를 붙여 교체하면 v1.0 언어로 정렬됩니다:

| 클래스 | 용도 |
|---|---|
| `.hy-card` / `.hy-card--flat` | 카드 표면(라운드22·소프트 그림자) |
| `.hy-row` | 아이콘·텍스트·액션 3분할 리스트 로우 |
| `.hy-btn .hy-btn--primary\|--secondary\|--ghost` | 버튼 3종 |
| `.hy-chip .hy-chip--safe\|--caution\|--brand\|--info` | 상태 칩/뱃지 |
| `.hy-icon-tile` | 카테고리·바로가기 3D 아이콘 틴트 타일 |
| `.hy-section-title` | 섹션 제목 |
| `.hy-sheet-handle` | 바텀시트 상단 그립 |
| `.hy-live-dot` | "실시간/추적 중" 펄스 점 |
| `.hy-rise-in` | 화면 진입 라이즈 인 모션 |

**권장 순서** (사용자 눈에 자주 닿는 순):
1. ✅ 부모 홈 — 이미 토큰 기반(포트 레이어만으로 완료)
2. ✅ 일정 추가 · 대화 · 조심할곳 · AI일정 — 교체본 포함
3. ✅ 위치·지도 마커 3종(지도·추적·길안내) — 교체본 포함, 파랑 마커 정리 완료
4. 스티커 — 의도된 수집성 다양성으로 유지(위 참고)
5. 설정·페어링·페이월 — 대부분 토큰 기반, 필요 시 추가 정리 가능

원하시면 위 화면부터 컴포넌트 단위로 직접 정리해 드릴게요.

## 함께 포함한 "정리된 컴포넌트" 7종

토큰만으로 안 잡히는 **낱개 색상**을 직접 걷어낸 교체본입니다. 각 파일을 앱의 같은 경로에
덮어쓰기만 하면 됩니다(로직·구조·문구 100% 보존, 색만 토큰화):

| 파일 | 정리한 내용 |
|---|---|
| `memo/MemoSection.jsx` | 대화 말풍선·구분선·입력창·전송버튼의 `#E5E7EB·#374151·#FAFAFA` → 따뜻한 토큰 |
| `parent/EventAddScreen.jsx` | 일정추가 프리셋·토글·반복선택의 파랑/회색 → 테마·중립 토큰 |
| `dangerZone/DangerZoneManager.jsx` | 조심할곳 입력·지도틀·타입버튼의 `#E5E7EB·#6B7280·#059669` → 토큰 |
| `aiSchedule/AiScheduleModal.jsx` | AI일정 입력창·로딩버튼의 `#E5E7EB·#9CA3AF` → 토큰 |
| `map/LocationMapView.jsx` | **파란 위치 마커·재중심 버튼** → 테마색, 도착=민트, 안내=앰버 토큰 |
| `childTracker/ChildTrackerOverlay.jsx` | 이동반경 원·예상경로선·범례·시트 핸들의 파랑/회색 → 브랜드·중립 |
| `route/RouteOverlay.jsx` | **길안내 경로선·"내 위치" 버튼**의 구글 파랑(`#4285F4`) → 브랜드색 |

> `ParentHomeScreen.jsx` 등은 이미 토큰만 쓰고 있어 **포트 레이어만으로 바로 v1.0** 이 됩니다
> (별도 교체 불필요).
>
> **스티커 팔레트는 일부러 그대로 뒀어요** — 칭찬 스티커는 종류마다 다른 파스텔색이
> "모으는 재미(수집성)"를 만드는 의도된 다양성이라, 5색으로 합치면 오히려 밋밋해집니다.
> 이미 밝은 파스텔이라 따뜻한 시스템과 충돌하지도 않아요. 통일을 원하시면 말씀해 주세요.
