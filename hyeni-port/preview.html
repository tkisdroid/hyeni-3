적용 방법 2분
  1. src/styles/redesign-system.css 를 프로젝트 같은 경로에 복사
  2. src/App.jsx 최상단의 import "./App.css"; 바로 아래에 import "./styles/redesign-system.css"; 추가
  3. npm run dev 로 확인 — 끝! (import 한 줄 지우면 100% 원복)
테마가 전부 바뀌는 원리 — 앱의 theme.js · applyThemeColor() 가 아이 색을 --theme-accent 계열 변수로 주입해요. 포트 레이어가 --primary·포커스 링·버튼·캘린더 선택일을 전부 --theme-accent 에 연결해 두었기 때문에, 색 하나만 바뀌면 위 데모처럼 모든 요소가 함께 그 색으로 통일됩니다.
