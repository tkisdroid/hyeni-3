# Google Play Console 출시 패키지 — 혜니캘린더 v1.4.6

기준일: 2026-09-07

패키지: `com.hyeni.calendar`

출시 후보: `versionName 1.4.6` / `versionCode 18`

현재 상태: 로컬 출시 준비 중. Play 사용 버전 확인·서명·AAB 업로드·검토 요청은 완료 뒤 증거로 갱신한다.

## 변경 내용

- 로그인 오류 중복, 실제 데이터 확인 시각, 하루 요약의 가족·아이·날짜 귀속을 수정한다.
- 네이티브 언어 동기화 테스트를 경량화하고 아이 학습 문구를 반말로 맞춘다.
- PWA 추가 언어 화면 문구를 지연 저장하며 첫 SW 제어 전 로드와 푸시 미지원 환경의 오프라인 문구도 보존한다.
- 한국어 소개는 학교 도착·준비물·수학 학습의 사용 이점을 먼저 설명하고 무료·프리미엄 위치 차이와 기존 투명한 모니터링 고지를 유지한다.
- `docs/store/play-listing.md`와 `store/global/source/ko-KR.json`이 한국어 소개 정본이다.
- 기존 외국어 전체 설명의 번역·원어민 검수 대기는 유지하며, 이번 한국어 소개 수정으로 외국어 검수 완료를 주장하지 않는다.

## 검증과 제출 경계

- 빌드 전 앱·Worker 테스트, typecheck, i18n, Android 테스트·lint와 production build를 확인한다.
- 서명은 운영자가 비밀번호를 직접 입력하고, 승인 upload certificate·package·버전·non-debuggable·웹 자산·16KiB ELF를 검증한다.
- 출시용 브랜치만 커밋하며 기존 main의 수정·미추적 파일은 보존한다.
- Worker/D1·Pages·실기기 설치는 이번 스토어 업데이트와 별도로 기록한다.
- Play 업로드 뒤 읽어온 버전과 검토 요청 상태가 확인돼야 제출 완료로 표시한다. 실제 게시 완료는 별도다.
