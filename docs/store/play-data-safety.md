# Play 데이터 보안(Data Safety) 설문 답안 — 혜니캘린더

코드 근거 기준으로 작성(2026-07-10). 서버 = Cloudflare Worker(hyeni-calendar-api) + D1 + R2.

## 총괄 답변
- 데이터를 수집하나요? **예**
- 데이터를 제3자와 공유하나요? **아니요** (가족 구성원 간 표시일 뿐, 제3자 제공·판매 없음. 단, AI 기능 사용 시 대화/사진 텍스트가 LLM API(OpenAI)로 처리 목적 전송 — "데이터 처리 목적의 서비스 제공자" 항목으로 선언)
- 전송 중 암호화? **예** (HTTPS/WSS 전용)
- 삭제 요청 수단 제공? **예** (앱 내 계정 삭제 + https://hyeni-calendar-api.tkisdroid.workers.dev/data-deletion)

|---|---|---|---|---|
| 위치 | 정확한 위치(백그라운드 포함) | 예(아이 기기) | 앱 기능(가족 위치 공유·도착/미도착 알림) | LocationService.java, child_locations |
| 개인 정보 | 이름 | 예 | 앱 기능(가족 구성원 표시) | family_members.name |
| 개인 정보 | 전화번호 | 예(선택) | 앱 기능(가입 인증·부모 전화 연결) | users.phone, member phone |
| 개인 정보 | 생일 | 예(선택) | 앱 기능(AI 친구 생일 인사) | family_members.birthdate |
| 사진·동영상 | 사진 | 예(선택) | 앱 기능(프로필·대화 사진 공유) | R2 child-photos |
| 오디오 | 음성 녹음 | 예(요청 시) | 앱 기능(주변 소리 듣기 1분 — 아이 알림 표시) | ambient/remote-listen |
| 오디오 | 음성 입력 | 예(요청 시) | 앱 기능(AI 음성 일정 등록, 기기 내 STT) | speech.ts(텍스트만 서버 전송) |
| 메시지 | 앱 내 메시지 | 예 | 앱 기능(가족 대화) | memo_replies |

| 앱 정보·성능 | 진단(배터리·네트워크 상태) | 예(아이 기기) | 앱 기능(기기 상태 안심 지표) | device_health |
| 기기 ID | 앱 설치 ID | 예 | 앱 기능(기기 바인딩 세션 보안), 사기 방지 | deviceInstallId |
| 금융 | 구매 내역 | 예(구독 시) | 앱 기능(프리미엄 엔타이틀먼트) | google-play-verify |

## 수집하지 않는 것
- 광고 없음·광고 ID 미사용, 위치/데이터 판매 없음, 제3자 광고 SDK 없음
- 연락처·SMS·통화기록 미수집 (CALL_PHONE은 다이얼 발신만)

## 아동 데이터 특기
- 아이 계정은 보호자 페어링 코드로만 생성(자체 가입 없음)
- 아이 위치·메시지는 같은 가족의 보호자에게만 표시
- 주변 소리 듣기는 실행 시 아이 기기에 알림 표시 + 1분 자동 종료 + 기록 화면 제공
