## 제출 전 문안 확인

- 위치·알림·SOS를 “항상”, “무조건”, “즉시”, “절대 놓치지 않음”으로 보장하지 않는다.
- 미도착은 오래되거나 정확도가 낮은 위치를 근거로 단정하지 않는 현재 동작과 맞춰 설명한다.
- SOS·기본 안전 알림을 프리미엄 혜택처럼 표현하지 않는다.
- 주변 소리 듣기는 아이 탭 없는 자동 연결, 최대 1분, 아이 화면·잠금 화면 지속 고지, 중지 동작, 감사 기록을 함께 설명한다.
- AI 결과는 사용자가 확인해야 하며 의료·법률·긴급 서비스의 판단처럼 표현하지 않는다.
- 공개 지원 이메일과 개인정보처리방침의 개인정보 담당 연락처를 동일하게 유지한다.
- AI 답변 신고는 앱 내 사유 선택·실패 재시도·중복 방지와 서버 소유권 검증·D1 영속 저장까지 구현되어 자동 회귀 테스트를 통과해야 한다. 실제 아이 화면과 운영 큐 E2E 증거가 없으면 제출 차단을 유지한다.
- 메모 신고·사용자 차단은 메시지 채널만 차단하고 SOS·위험·위치 안전 채널을 유지하도록 구현되어 자동 회귀 테스트를 통과해야 한다. 실제 부모·아이 양방향 E2E와 운영 절차 확인 전에는 제출 차단을 유지한다.

## 대상 연령 결정

혜니캘린더는 보호자와 아이 모드를 함께 제공하므로 실제 이용자를 근거로 보호자+아동 혼합 연령과 구체적인 연령 구간을 결정해야 한다. 현재 기능 구성에서 다음 선택과 검증은 출시 차단 조건이다.

- 아이 모드에서 아동이 직접 일정·대화·SOS·AI 기능을 사용하므로 심사를 피하기 위한 성인 전용 선택을 금지한다.
- 정밀·백그라운드 위치를 유지하는 현재 앱의 아동 전용 제출을 금지한다.
- 혼합 연령을 선택해도 아이 경로에서 접근 가능한 API/SDK의 Families 적격성 증거가 없으면 해당 기능을 아이 경로에서 코드로 차단하고 차단 E2E를 남긴다.
- Families 검증 범위에는 Firebase/FCM, Kakao 지도·경로, 공개 OSRM, OpenAI, Android `SpeechRecognizer`·Web Speech 등 아이가 직접 또는 간접 사용하는 모든 외부 처리를 포함한다.
- 실제 대상과 맞지 않는 연령대를 정책 회피 목적으로 추가하거나 제외하지 않는다.
- 최종 결정과 근거를 Play Console 제출 기록에 남기기 전까지 출시를 승인하지 않는다.
