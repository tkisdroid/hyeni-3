# Play 출시 노트 — 1.4.9 (versionCode 21)

## 한국어

- 해외 가족의 아이 위치 확인에 Google 지도를 지원합니다.
- 위치·도착·안전 알림을 선택한 언어와 가족 현지 시간에 맞게 개선했습니다.
- 장소 검색과 위치 이력, 알림 표시의 안정성을 개선했습니다.

## 영어

- Google Maps support for viewing your child's location outside Korea.
- Location, arrival and safety alerts now use your selected language and family time zone.
- Improved place search, location history and notification display reliability.

## 제출 전 확인

- 2026-09-14 시스템 Chrome의 Play Console 전체 번들 목록: 최대 업로드 code 20(1.4.8), 공개 code 19(1.4.7).
- 이번 후보는 code 21이며 과거 code 20 AAB를 재사용하지 않는다.
- 실기기 검증은 사용자 지시로 생략했다. 실기기·실제 푸시 수신 검증 통과로 표현하지 않는다.
- Google 도보 경로는 비활성 상태를 유지하며 이번 출시 노트에서 지원을 약속하지 않는다.
- AAB 서명·업로드·검토 신청은 각 단계의 실제 결과를 별도로 기록한다.
