## 4. 다시 겪지 말아야 할 함정 (Play Console 브라우저 자동화)

- **요소 클릭·`set-value` 는 창 포커스 없이 동작**하지만, `press-key` 와 좌표 클릭은
  `open -a "Google Chrome"` 로 포커스를 잡은 **직후에만** 성공한다. 아니면 `window_not_focused`.
  포커스가 필요한 단계는 한 명령 안에서 `open -a` → `sleep` → `orca computer ...` 로 이어 붙인다.
- **스크린샷 이미지에는 접근성 라벨·프레임이 없다**(`elementFrames` 미제공, 트리에는 "휴대전화 스크린샷"만).
  그래서 **드래그 재정렬을 시도하지 말고 파일 업로드로 처리**한다.
- 언어 전환 = 언어 드롭다운(요소 클릭) → `Down`/`Up` n회 → `Return`. 목록 순서는
  `ko-KR, ms-MY, vi, en-US, id, ja-JP, zh-CN, zh-TW, th, fil` 이고 **마지막(fil)에서 `Down` 은 더 이상 움직이지 않는다**(래핑 없음).
- `?locale=en-US` 쿼리는 **무시**된다. `?hl=en-US` 는 **콘솔 UI 언어만** 바꾼다(목록 언어 아님).
- 저장 후에는 반드시 **문자 수 카운터로 read-back** 한다(`/30`·`/80`·`/4000`). 값이 실제로 들어갔는지는
  스낵바 "변경사항이 저장되었습니다"와 카운터가 함께 확인돼야 한다.
- 저장만으로는 공개되지 않는다. **게시 개요 → "검토를 위해 변경사항 N개 제출"** 까지 눌러야 하며,
  그 뒤에도 이전 승인 건이 끝날 때까지 공개 페이지는 옛 문구를 유지한다.
- Play Console 앱 URL은 패키지명이 아니라 **숫자 app id** 를 쓴다:
  `https://play.google.com/console/u/0/developers/5454444916579168584/app/4973968570577959797/main-store-listing`
  (`~/app/<package>` 형태로 열면 `예기치 않은 오류가 발생했습니다` 화면이 뜬다.)
