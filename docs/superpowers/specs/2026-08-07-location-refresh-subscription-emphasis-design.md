# 위치 요청 피드백·구독 카드 강조 디자인

## 목표

부모 위치 화면에서 위치 요청 진행 안내가 아이 프로필을 가리지 않게 하고, 부모 홈 구독 카드는 다른 보조 카드보다 쉽게 발견되도록 강조한다.

## 위치 요청 피드백

- 지도 위에 독립적으로 떠 있던 `.pl-refreshing` 안내창은 제거한다.
- 위치 요청 중 상태는 기존 활성 아이 칩 `.pl-chip` 안에서 프로필·아이 이름과 함께 표시한다.
- 프로필 이미지는 항상 유지하고, 오른쪽 상태 점만 spinner로 전환한다.
- 상태 문구는 기존 계약대로 `위치 요청을 보냈어요` 한 줄만 사용한다.
- 새로고침 버튼 회전, 하단 상세 카드의 위치 요청 상태, `aria-live="polite"`는 유지한다.
- 다자녀·작은 화면에서도 칩은 최대 화면 너비를 넘지 않고 이름과 상태 문구를 말줄임한다.

## 구독 카드 강조

- 카드 전체가 구독 화면으로 이동하는 기존 동작과 무료·유료·미확정 진실 상태를 유지한다.
- Free·reviewed의 `benefits` 카드는 보라–분홍 계열 그라데이션, 강조 테두리와 그림자, 더 큰 아이콘으로 가장 강하게 보인다.
- Premium의 `manage` 카드는 민트 계열 그라데이션을 사용하고 `관리하기` CTA를 표시한다.
- 미확정·오류의 `neutral` 카드는 중립 배경을 유지하며 상태를 Free로 추정하지 않는다.
- 상태별 CTA는 `혜택 보기`·`관리하기`·`확인하기`이며, 카드 전체가 버튼이므로 내부 CTA는 장식 텍스트로만 둔다.
- 실제 체험 종료일·구독 종료일 외의 가짜 긴급성, 할인율, 공포 문구는 추가하지 않는다.

## 접근성·회귀

- 모든 색상·그림자·radius는 기존 디자인 토큰을 사용한다.
- 구독 카드는 44px 이상 조작 영역과 키보드 초점 계약을 유지한다.
- 위치 요청 중 아이 칩의 프로필 가시성, 상태 문구, 독립 오버레이 제거를 회귀 테스트로 고정한다.
- 구독 카드 상태 resolver가 CTA 문구까지 반환하도록 하고 무료·Premium·미확정 분기를 순수 테스트로 검증한다.
- 격리 브라우저 QA에서 위치 칩과 무료·Premium 구독 카드의 렌더링·오버플로를 확인한다.

## 범위 밖

- 위치 요청 API·폴링 시간·요청 횟수 정책은 바꾸지 않는다.
- 구독 가격·혜택·결제 흐름은 바꾸지 않는다.
- 실제 아이 기기 벨·SOS·주변소리는 검증 과정에서 실행하지 않는다.
