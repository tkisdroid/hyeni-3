# 부모 ‘오늘 경로’ 화면 전면 재설계

## 목표

부모가 화면을 연 직후 다음 세 가지를 빠르게 이해할 수 있게 한다.

1. 아이가 선택한 날 언제부터 언제까지 이동했는지
2. 어떤 순서로 이동했고 어디에 얼마나 머물렀는지
3. 특정 시각 또는 머문 장소가 지도상 어디인지

현재처럼 날짜 선택, 시간 슬라이더, 지도, 드래그 시트가 서로 겹치는 구조를 없앤다. 실시간 위치 화면의 데이터 계약과 위치 티어 정책은 바꾸지 않는다.

## 확정한 접근

‘지도 + 통합 이동 타임라인 패널’을 사용한다.

- 지도는 화면의 주 시각화로 유지한다.
- 날짜 선택은 지도 상단의 작은 도구막대 하나로 통합한다.
- 시간 따라보기, 선택 시각의 상태, 머문 장소 목록은 하나의 하단 패널에 배치한다.
- 패널은 드래그 제스처에 의존하지 않는다. 명확한 펼치기/접기 버튼을 제공한다.
- 목록에서 장소를 선택하면 지도 마커와 카드가 같은 순번·같은 강조색으로 연결된다.
- 머문 장소가 없어도 경로 패널을 유지하고 ‘이동 기록은 있지만 오래 머문 곳은 없어요’라고 정직하게 설명한다.

목록만 보여주는 전체 화면 방식은 지도 맥락이 약하고, 기존 화면의 색상·간격만 수정하는 방식은 겹침과 인지 부하를 해결하지 못해 제외한다.

## 정보 구조

### 1. 상단 보기 전환

- 기존 `최근 위치/실시간`과 `오늘 경로/이동 기록` 탭을 유지한다.
- 현재 디자인 토큰과 44px 최소 조작 영역을 유지한다.
- 경로 화면에서는 새로고침 버튼을 노출하지 않는다.

### 2. 날짜·아이 도구막대

- 활성 아이의 아바타와 이름을 표시해 어떤 아이의 경로인지 항상 알 수 있게 한다.
- 가운데에 선택 날짜를 사람이 읽기 쉬운 레이블로 표시한다.
- Premium은 이전/다음 날짜와 날짜 입력을 사용할 수 있다.
- Free는 오늘만 실제 조회하고 이전 날짜 동작은 기존 업셀 계약을 유지한다.
- 도구막대는 지도 내용을 최소한으로 가리키는 한 줄 카드로 만든다.

### 3. 지도

- 이동선, 출발점, 아이 위치, 일정 장소, 머문 곳 마커의 데이터 계약은 유지한다.
- 머문 곳 마커와 타임라인 항목은 같은 순번을 사용한다.
- 선택한 머문 곳 또는 선택 시각으로 지도를 이동하는 기존 우선순위를 유지한다.
- Kakao 지도에 상단 도구막대와 하단 패널 높이를 반영하는 bounds padding을 전달해 경로가 UI 아래에 가려지지 않게 한다.
- 최신 따라가기 상태에서는 하루 전체 경로가 안전 영역 안에 보이게 한다.

### 4. 통합 이동 타임라인 패널

패널 헤더에는 다음 정보를 표시한다.

- `<아이 이름>의 오늘 경로` 또는 선택 날짜 경로
- 기록 시작 시각–마지막 확인 시각
- 머문 곳 개수
- 명시적 펼치기/접기 버튼

패널 본문은 두 영역으로 구성한다.

#### 시간 따라보기

- 현재 선택 시각을 가장 크게 표시한다.
- 같은 줄에 `학교`, `이동 중`, `기록 없음` 중 정본 데이터로 판정한 상태를 표시한다.
- 슬라이더와 시작/끝 시각을 배치한다.
- 사용자가 과거 시각을 고른 경우에만 `최신으로` 버튼을 활성화한다.
- 시간 슬라이더를 움직여도 패널이 자동으로 사라지지 않는다.

#### 머문 곳 타임라인

- 세로 연결선과 순번 마커를 사용해 방문 순서를 한눈에 보여준다.
- 각 항목은 장소명, 도착–출발 시각, 체류 시간을 표시한다.
- 선택 항목은 mint 계열 배경·경계로 강조하고 지도 마커도 같은 상태를 사용한다.
- 장소명이 없으면 `확인되지 않은 장소`라고 표시해 등록 장소처럼 보이지 않게 한다.
- 머문 곳이 없으면 빈 카드 대신 짧은 설명을 보여주되 시간 따라보기는 계속 사용할 수 있다.

## 상태별 동작

### 로딩

- 중앙의 떠 있는 토스트 대신 하단 패널 안에 skeleton과 `이동 기록을 불러오는 중…` 상태를 표시한다.
- 지도는 유지해 화면 전환 시 시각적 점프를 줄인다.

### 빈 기록

- `이 날은 확인된 이동 기록이 없어요`를 패널에 표시한다.
- 선택 날짜와 아이 정보는 남겨 사용자가 무엇을 조회했는지 알 수 있게 한다.

### 조회 실패

- 패널 안에 오류 설명과 44px 이상의 `다시 시도` 버튼을 제공한다.
- 이전 캐시를 새 기록처럼 표시하지 않는다.

### 경로는 있고 머문 곳은 없음

- 이동선과 시간 따라보기는 그대로 제공한다.
- `8분 이상 머문 것으로 확인된 장소가 없어요`라고 검출 기준을 과장 없이 설명한다.

## 컴포넌트 경계

- `ParentLocation`: 티어, 날짜, 위치 이력 쿼리, 지도 중심과 선택 상태를 소유한다.
- `LocationHistoryToolbar`: 활성 아이와 날짜 선택 UI만 담당한다.
- `LocationJourneyPanel`: 요약, 시간 따라보기, 머문 곳 타임라인, 로딩·빈·오류 상태를 담당한다.
- `KakaoMap`: 선택된 경로·마커 렌더링과 viewport padding만 담당한다.
- 순수 계산은 기존 `locationHistoryScrub.ts`, `stayPoints.ts`를 유지하고 필요한 요약 계산만 별도 transform에 추가한다.

컴포넌트는 서버 응답을 직접 해석하지 않고 `ParentLocation`에서 정규화한 값만 받는다.

## 시각 원칙

- 앱의 기존 white card, mint 의미색, 디자인 토큰, radius 계층을 사용한다.
- lavender는 장식 위주로 제한하고 경로 선택 상태는 지도와 일치하는 mint를 사용한다.
- 지도 위 반투명 카드 수를 줄이고 한 화면에 강한 그림자는 최대 두 레이어만 사용한다.
- 본문 14px 이상, 보조 문구는 기존 caption 토큰, 모든 버튼은 최소 44px을 유지한다.
- portrait에서는 하단 전체 폭 패널을 사용한다. 720px 이상 또는 가로 모드에서는 패널을 화면 왼쪽에 392px 고정 폭으로 배치하고 지도 중심·bounds padding도 오른쪽의 남은 지도 영역을 기준으로 잡는다.
- `prefers-reduced-motion`에서는 패널·지도 전환 애니메이션을 제거한다.

## 접근성

- 드래그만으로 가능한 동작을 제거한다.
- 펼치기 버튼에 `aria-expanded`와 패널 연결 정보를 제공한다.
- 날짜 이동, 최신으로, 장소 선택은 각각 명확한 accessible name을 갖는다.
- range에는 선택 시각과 장소 상태를 `aria-valuetext`로 전달한다.
- 로딩은 `role=status`, 오류는 `role=alert`로 전달한다.

## 데이터·보안 영향

- API, Worker, D1, 위치 티어, 날짜 범위 계약은 변경하지 않는다.
- 위치 이력 원본이나 좌표를 새 저장소에 복제하지 않는다.
- analytics 이벤트를 추가하지 않는다.
- 활성 아이 식별 우선순위를 그대로 유지하고 첫째 폴백을 추가하지 않는다.

## 검증

### 자동 회귀

- 시간 선택에 따른 지도 중심 우선순위와 상태 라벨 테스트
- 경로가 있으나 머문 곳이 없는 상태 테스트
- 날짜 티어 계약과 Premium 30일 범위 테스트
- 패널 펼치기/접기 접근성 테스트
- 지도 bounds padding과 선택 마커 연동 테스트
- 기존 route accuracy, design token, contrast, viewport 테스트 갱신
- `npm run typecheck`, `npm test`, `npm run build`

### 시각·실기기

- 390px 모바일 WebKit에서 세로 오버플로·가로 오버플로·콘솔 오류 확인
- A17 부모 세션을 보존한 채 오늘 경로를 2회 확인
- portrait와 landscape에서 경로·상단 도구막대·하단 패널이 서로 가리지 않는지 확인
- S25에는 접근하지 않는다.

## 완료 기준

- 화면 진입 직후 아이, 날짜, 경로 범위, 머문 곳 수를 이해할 수 있다.
- 지도 이동선과 머문 곳 목록의 순서가 명확히 연결된다.
- 날짜, 시간, 목록 조작이 서로 화면을 갑자기 숨기거나 덮지 않는다.
- 머문 곳이 0개인 날에도 오늘 경로 기능을 계속 사용할 수 있다.
- 기존 위치 티어·데이터 정확성·활성 아이 계약이 모두 유지된다.
