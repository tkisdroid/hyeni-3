# 부모 홈 구독·아이 기기 찾기 재배치 설계

## 목표

부모 홈에서 아이 기기 찾기를 바로 발견할 수 있게 하고, 구독 진입점은 현재 이용 상태에 맞는 가로형 카드로 분리한다. 기존 홈의 3D 아이콘, 카드 표면, 4열 바로가기와 존댓말 문구를 유지한다.

## 정보 구조

- 바로가기 4×2 그리드는 `AI 일정 → 위치추적 → 친구놀이 → 장소관리 → 주변소리 → 안심리포트 → 아이 기기 찾기 → 알림` 순서로 유지한다.
- `아이 기기 찾기`는 `/remote-ring`으로 이동하며, 현재 활성 아이의 `user_id`를 route state로 명시한다. 활성 아이가 없거나 기기가 연결되지 않았을 때는 기존 RemoteRing 화면이 정직한 연결 상태를 안내한다.
- 구독은 바로가기 그리드에서 제거하고 그리드 아래에 `아이와 대화하기`와 같은 폭의 가로형 카드로 배치한다. 기능 바로가기를 구독 홍보보다 먼저 보여 홈의 우선순위를 보존한다.

## 구독 상태별 표시

- 엔타이틀먼트가 확정된 Free/기존 reviewed 가족: 제목 `구독 시 혜택`, 설명 `실시간 위치와 더 넉넉한 가족 기능을 확인해 보세요`, 보조 문구 `현재 무료 플랜`.
- Premium 가족: 제목 `구독 관리`, 설명은 정본 `planLabel`, 보조 문구는 체험 중이면 남은 체험 일수, 그 외에는 결제 주기 종료일이 있으면 종료일, 없으면 `이용 중`으로 표시한다.
- 판정 중: `구독 정보`와 `이용 상태를 확인하고 있어요`를 표시한다.
- 조회 오류: 캐시된 정본이 없을 때 Free로 추정하지 않고 `구독 정보`와 `이용 상태를 확인하지 못했어요`를 표시한다.
- 모든 상태에서 카드를 누르면 `/subscription`으로 이동한다.

## 구현 경계

- 상태별 문구는 순수 변환 함수로 분리해 Free/Premium/unknown/error를 독립 검증한다.
- 서버·결제·엔타이틀먼트 판정 로직은 변경하지 않고 기존 `useEntitlement()` 결과만 소비한다.
- 새 아이콘은 만들지 않고 기존 `ui/phone-lavender.webp`, `ui/menu-subscription.webp`를 재사용한다.
- 기존 반경·색상·간격 토큰, 최소 44px 조작 영역, `hy-press` 눌림 피드백을 유지한다.

## 검증

- 순수 테스트: 구독 카드 문구가 Free/Premium/unknown/error를 정확히 구분하고 unknown/error를 무료로 강등하지 않는다.
- 계약 테스트: 바로가기에서 구독이 빠지고 아이 기기 찾기가 들어가며, 활성 아이 `user_id`를 RemoteRing에 전달한다.
- UI 검증: 384px A17 뷰포트에서 4×2 그리드, 가로형 구독 카드, 가로 오버플로, 터치 영역, 콘솔 오류를 확인한다.
- 실기기에서는 소리 울리기를 실제 발사하지 않고 진입 화면과 대상 아이만 읽기 전용으로 확인한다.
