# 영단어 5단계와 부모 풀이 기록

## 사용자 요청

미니앱에서 수준별 영단어를 플립카드로 학습하고, 부모도 아이가 풀었던 문제를 확인한다. 사용자는 5단계를 선택했고, 단어 수를 최대한 늘리며 수학도 실제 문항을 조회하도록 요청했다.

## 화면과 학습 내용

- 미니앱에 `영단어` 진입점을 추가한다. 아이는 학습 화면, 부모는 현재 선택한 아이의 영어 기록으로 이동한다.
- 첫걸음·기초 쌓기·생활 영어·실력 넓히기·도전 어휘의 5단계에 352/352/813/1,322/1,228개, 총 4,067개 단어를 제공한다. CEFR-J 수준 자료를 참고한 자체 학습 순서이며 공식 학년별 필수 범위나 인증 등급을 주장하지 않는다.
- 카드 앞면은 영단어, 뒷면은 품사·한국어 뜻을 보여 준다. 위키낱말사전의 재배포 가능한 뜻을 사용하며 검증하지 않은 예문·음원은 포함하지 않는다. 탭과 키보드로 뒤집을 수 있고 동작 줄이기 설정을 따른다.
- 아이가 `알겠어` 또는 `다시 볼래`를 누르면 해당 카드의 평가를 서버에 저장한다. 실패하면 카드와 재시도 키를 유지한다. 재시도 성공 전에는 다음 카드로 이동하지 않는다.
- 새 단어·복습·모든 단어를 선택한다. 카드는 서버에서 40개씩 받으며 저장으로 목록이 줄어도 커서는 원본 카탈로그 위치를 기준으로 진행한다. 완료 화면에서는 단계 선택으로 돌아간다.
- 영어 단계는 수학 학년을 바꾸지 않는다. 학년이 미설정이거나 초등 3~6학년 밖인 아이도 현재 가족의 활성 아이이면 영어를 학습할 수 있다.
- 부모 영어 기록에는 단계별 확인 단어·다시 볼 단어·최근 평가를 보여 준다. 아이의 자가평가를 정답률이나 객관적 숙련도로 표시하지 않는다.
- 부모 수학 화면에 `푼 문제`를 추가한다. 실제 문항·시각·제출 답·정오답·시도 횟수·힌트 사용·정답·해설을 확인한다. 7일/30일/학기 범위를 유지하고 20건씩 더 불러온다.
- 문항/해설은 풀이 당시 콘텐츠 릴리스로 조회한다. 원본이 없는 과거 기록은 상세 확인 불가로 표시하며 생성 문항이나 가짜 해설로 채우지 않는다.

## 소유권과 저장

`hyeni-3`는 화면·Calendar 인증·가족·권한·HTTP gateway를 소유한다. `math-explorer`는 Study RPC·학습 콘텐츠·D1 기록을 소유한다. 두 작업은 기존 수정 사항을 보존한 `feat/study-vocabulary-history`에서 진행한다.

영어 카탈로그는 Study의 별도 버전과 단어 ID를 사용한다. 기존 수학의 3,384문항 릴리스, 학년, 미션은 보존한다. `vocabulary_reviews`에 profile ID·단어 ID·단계·자가평가·서버 시각·멱등 요청 ID·입력 지문을 저장하고, `vocabulary_progress`에 단어별 최신 평가를 보관한다. 두 변경은 아이별 DO 직렬화와 한 D1 batch로 확정한다. 자유 답안·기기 식별자·위치·새 인증 정보는 수집하지 않는다.

학년 없는 영어 학습은 동일한 Calendar 연결 프로필의 identity만 생성한다. 이후 수학 진입은 학년 선택 상태를 반환하고 기존 프로필을 보완한다. 조회는 현재 가족의 활성 프로필만 사용한다. 기존 Study production wrapper에는 detach/purge RPC가 없으며, legacy 프로필 잠금은 삭제가 아니라 보존이다. 이 변경으로 계정 삭제 전체 경로를 구현·검증했다고 주장하지 않는다.

## RPC와 권한

| HTTP 경로 | Study RPC | 서명 operation |
| --- | --- | --- |
| `GET /api/study/children/:memberId/history` | `getChildProblemHistory` | `guardian.history` |
| `GET /api/study/children/:memberId/vocabulary` | `getChildVocabularyProgress` | `guardian.vocabulary` |
| `GET /api/study/learner/vocabulary` | `getVocabularyDeck` | `learner.vocabulary.read` |
| `POST /api/study/learner/vocabulary/reviews` | `recordVocabularyReview` | `learner.vocabulary.review` |

모든 신규 operation의 학년은 선택 사항이다. Calendar는 현재 가족의 활성 부모/제2 부모와 명시한 아이를 다시 검증한다. 아이의 member ID는 인증 사용자에서 결정하며 요청 body에서 받지 않는다. Study는 operation·서명·입력 지문·정확한 family/member를 검증한다. 새로운 public Study HTTP나 로그인은 만들지 않는다.

히스토리 cursor는 범위·대상 프로필·최근 시각·시도 ID에 묶고 한 페이지 최대 20건이다. 영어 평가는 같은 요청 ID와 같은 입력이면 같은 결과를 반환하고 다른 입력이면 충돌로 종료한다. 계정/아이/단계 전환 후 늦은 응답이 다른 화면 상태를 바꾸지 않도록 query key와 컴포넌트 상태를 분리한다.

## 검증과 운영 경계

격리 D1 테스트에서 가족/형제 격리, 학년 없음, 영어 후 수학 진입, 멱등 재시도, 동시 저장, 원래 문항 릴리스, 페이지 경계, 잠금 프로필 제외를 검증한다. 앱은 11종 제출 답 표시, 카드 뒤집기·저장 실패·복습·빈 기록·오류·아이 전환을 검사한다. 모바일/데스크톱 Playwright 검증은 fixture API로 수행하므로 실제 운영 API E2E와 구분한다.

운영에는 Study D1 migration 0010을 먼저 적용하고 Study Worker → Calendar Worker → 앱 순서로 반영해야 한다. schema 9의 기존 Worker는 migration 10 직후 준비 상태가 닫히므로 변경 창 안에서 이어서 배포해야 한다. 구현·로컬 검증과 운영 배포·실기기 확인을 구분한다. 현재 기기의 로그인·역할·페어링·refresh 토큰을 변경하지 않는다.
