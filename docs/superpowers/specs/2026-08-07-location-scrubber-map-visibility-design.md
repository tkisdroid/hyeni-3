# 오늘 이동기록 시간 탐색과 지도 위치 가시성 개선

## 1. 목표

부모가 `오늘 이동 기록`의 시간 막대를 연속으로 움직이면서도 선택한 시각, 그 시각의 위치 설명, 지도 위 아이 마커를 한 화면에서 즉시 확인할 수 있게 한다. 위치 기록이 없는 구간이나 머문 곳으로 확정되지 않은 구간은 기존처럼 정직하게 `기록 없음` 또는 `이동 중`으로 표시한다.

## 2. 재현과 근본 원인

2026-08-07 A17 부모 모드에서 프로덕션 앱의 `#/parent/location?view=history`를 확인했다. 시간 막대를 15:02에서 10:28로 옮겼을 때 다음 상태가 반복 재현됐다.

- WebView 높이: 832px
- 펼친 이동기록 패널: y=313~696
- 선택 시각 아이 마커 중심: y=386
- `elementFromPoint` 결과: 아이 마커가 아니라 `.pl-journey__body`

데이터 계산은 정상이다. 막대 값, 선택 시각, 위치 설명, 아이 좌표가 모두 바뀌었다. 그러나 최근 재설계에서 시간 막대를 움직여도 큰 패널을 펼친 채 유지하도록 바뀌었고, `KakaoMap`의 `viewportPadding`은 `setBounds`에만 적용된다. 선택 시각은 명시적 `center` 경로에서 `setCenter`만 호출하므로 마커가 지도의 기하학적 중앙, 즉 패널 뒤로 이동한다.

고정 여백값도 실제 패널 크기와 일치하지 않는다. 글자 크기, 머문 곳 개수, 화면 높이에 따라 패널 위치가 달라지므로 상수만 조정하면 같은 문제가 다시 생긴다.

## 3. 검토한 접근

### 3.1 지도 중심만 고정값으로 위로 이동

수정량은 작지만 큰 머문 곳 목록이 계속 지도를 가리고 기기 높이·글자 크기 변화에 취약하다. 선택하지 않는다.

### 3.2 시간 조작 즉시 패널 전체 접기

지도는 넓어지지만 첫 조작 뒤 시간 막대가 사라져 연속 탐색을 할 수 없다. 선택하지 않는다.

### 3.3 시간 탐색 영역 유지 + 머문 곳 목록만 자동 접기 + 실측 여백 중심 보정

선택 시각·위치 설명·시간 막대는 항상 남긴다. 사용자가 막대를 움직이면 머문 곳 목록만 접어 지도를 넓히고, 실제 도구막대와 패널 경계를 측정해 아이 마커를 가려지지 않는 지도 영역 중앙에 둔다. 조작과 결과를 동시에 볼 수 있으므로 이 방식을 채택한다.

## 4. 상호작용 설계

### 4.1 이동기록 패널

- 이동 기록이 있어 시간 재생이 가능한 상태에서는 패널 헤더와 시간 탐색 카드(선택 시각, 위치 설명, `최신 위치`, range input)가 항상 보인다.
- 펼침 상태는 `머문 곳` 타임라인의 표시 여부만 제어한다.
- 사용자가 시간 막대를 움직이면 머문 곳 타임라인만 자동으로 접는다. 시간 막대는 사라지지 않는다.
- 헤더 버튼으로 머문 곳 타임라인을 다시 펼치거나 접을 수 있다.
- 머문 곳이 없는 loading/error/empty/moving-only 상태에서는 헤더를 상세 토글로 위장하지 않고 상태 또는 시간 탐색만 표시한다.
- 60초 위치 이력 폴링은 선택 시각과 타임라인 펼침 상태를 바꾸지 않는다.
- `최신 위치`를 누르면 기존처럼 최신 따라가기로 돌아가되 머문 곳 타임라인은 사용자가 정한 상태를 유지한다.

### 4.2 지도 포커스

- 날짜 도구막대 아래와 이동기록 패널 위 사이를 `가시 지도 영역`으로 정의한다.
- 모바일은 실제 도구막대 하단과 패널 상단을 측정해 top/bottom padding을 계산한다.
- 가로 넓은 화면은 왼쪽 패널의 실제 오른쪽 경계를 측정해 left padding을 계산한다.
- 명시적 `center`에도 이 padding을 적용한다. 아이 좌표를 먼저 지도 중앙에 둔 뒤 padding 차이만큼 지도를 이동해 아이 마커가 가시 영역 중앙에 오게 한다.
- 패널 크기, 방향, viewport 크기가 바뀌면 `ResizeObserver`와 resize 이벤트로 padding을 다시 계산한다.
- 지도 중심과 아이 마커 좌표는 계속 분리한다. 머문 곳을 눌러 지도를 이동해도 아이 마커 좌표를 머문 곳 중심으로 위조하지 않는다.

### 4.3 선택 시각 강조

- 시간 막대가 머문 곳의 `[arrivalMs, departureMs]` 안에 있으면 해당 머문 곳 행과 지도 마커를 자동 강조한다.
- 사용자가 머문 곳 행을 직접 선택한 상태는 그 선택을 우선한다. 다시 시간 막대를 움직이면 직접 선택을 해제하고 시간 기준 강조로 돌아간다.
- 아이 아바타 마커는 머문 곳 마커보다 높은 z-index로 렌더한다.
- 과거 시각을 고른 동안 아바타에 선택 시각 배지를 붙여 현재 위치가 아니라 선택 기록임을 분명히 한다. 최신 따라가기 상태에서는 배지를 표시하지 않는다.

## 5. 컴포넌트와 데이터 흐름

### `ParentLocation`

- 기존 위치 이력, `scrubMs`, `scrubChildPoint`, `scrubWhere` 계산은 유지한다.
- 시간에 해당하는 머문 곳 인덱스를 순수 함수로 계산한다.
- 도구막대·패널 DOM 경계를 측정해 `KakaoMap.viewportPadding`을 만든다.
- 시간 조작 시 `historyPanelExpanded=false`로 머문 곳 목록만 접는다.
- 과거 시각일 때 `historyChildMarker`에 선택 시각 배지를 전달한다.

### `LocationJourneyPanel`

- 시간 탐색 영역과 머문 곳 상세 영역을 분리한다.
- `expanded`와 `aria-expanded`는 머문 곳 상세 영역에만 대응한다.
- 접힌 상세 영역은 `hidden`으로 키보드·스크린리더 포커스에서 제외한다.
- loading/error/empty 상태 문구와 재시도 동작은 유지한다.

### `KakaoMap`

- `setBounds`뿐 아니라 명시적 `center`에도 정규화된 padding을 적용한다.
- padding 변경만으로도 같은 좌표를 다시 배치한다.
- 선택 시각 배지가 있는 아이 마커를 머문 곳 마커보다 위에 렌더한다.

### 순수 변환

- DOMRect와 viewport 크기에서 지도 padding을 계산하는 함수는 브라우저 밖 단위 테스트가 가능하게 분리한다.
- 선택 시각에 해당하는 머문 곳 인덱스 계산도 순수 함수로 둔다.

## 6. 오류와 경계 상태

- 선택 시각 이전에 실측점이 없으면 현재 위치를 과거 위치처럼 대체하지 않고 마커를 만들지 않으며 `기록 없음`을 유지한다. 최신 따라가기에서만 현재 위치를 이력 마커의 안전한 폴백으로 쓴다.
- 실측점은 있지만 머문 곳이 아니면 마커를 표시하고 `이동 중`을 유지한다.
- 위치 이력 오류에서는 현재 위치가 있더라도 선택 시각 위치처럼 보이지 않는다.
- `ResizeObserver`가 없는 환경에서는 resize 이벤트와 안전한 기본 padding으로 강등한다.
- 측정값이 비정상·음수·무한이면 0 이상 viewport 범위로 정규화한다.
- 사용자가 지도를 직접 더 확대했다면 기존처럼 강제 축소하지 않는다.

## 7. 접근성과 시각 규칙

- range input의 44px 조작 영역과 `aria-valuetext="시각 · 위치"`를 유지한다.
- 머문 곳 펼침 버튼은 실제 상세 영역 id를 `aria-controls`로 가리킨다.
- 자동 접힘은 시간 막대를 제거하거나 포커스를 이동시키지 않는다.
- 새 색상은 기존 mint·surface·foreground 토큰을 사용한다.
- reduced motion에서는 마커 배지와 패널 전환을 정적으로 표시한다.

## 8. 검증 기준

### 자동 테스트

- 선택 시각이 머문 곳 범위 안팎과 경계 시각에서 올바른 인덱스를 반환한다.
- 실제 toolbar/panel rect에서 계산한 padding이 가시 영역을 정확히 남긴다.
- 명시적 center가 padding 차이만큼 `panBy`되고 padding 변경에도 재적용된다.
- 시간 조작이 머문 곳 상세만 접고 range input을 계속 렌더한다.
- 선택 시각 머문 곳과 아이 마커 우선순위·시간 배지 계약을 보호한다.
- 기존 위치 이력, 경로 실선, 지도 bounds, 모바일 viewport, 디자인 시스템 검증을 통과한다.

### 브라우저·A17

- 390×844 격리 브라우저와 A17에서 시간 막대를 시작·중간·끝으로 연속 이동한다.
- 각 이동 뒤 선택 시각과 위치 설명이 갱신되고 아이 마커 전체가 toolbar와 panel 사이에 보인다.
- `elementFromPoint`가 패널이 아니라 아이 마커를 반환한다.
- range input은 첫 이동 뒤에도 계속 보이고 조작 가능하다.
- 머문 곳 시간 안에서는 해당 행과 지도 마커가 강조된다.
- 최신 위치 복귀, 타임라인 재펼침, 수평 overflow 0, 콘솔 오류 0을 확인한다.
- A17 부모 세션·가족 일치를 유지하고 `adb install -r`만 사용한다. SOS·소리 울리기·주변 소리는 실행하지 않는다.

## 9. 범위
