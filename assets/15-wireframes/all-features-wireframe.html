Entry / Auth / Pairing

처음 가입, 기존 회원 재로그인, OAuth 계정 연결, 가족 생성, 아이 페어링을 한 흐름으로 연결합니다.

Parent Mode

부모 홈, 일정, 위치, 장소, 대화, 스티커, SOS, 주변소리, 친구놀이, 설정, 가족, 구독을 포함합니다.

0개

Child Mode

아이 홈, AI 친구, 부모님에게 이야기하기, SOS, 권한, 위치, 친구놀이, 구독 상태를 포함합니다.

0개

Teacher Mode

선생님 인증 후 반 생성, 반 관리, 출석, 알림장, 부모 승인 기반 공유 범위를 설명합니다.

0개

Common Overlays / Exceptions

알림, 권한, 결제, 데이터, 오류, 하단 시트처럼 모든 모드에서 흐름을 끊지 않아야 하는 상태입니다.

0개

Isolation Rules

가장 중요한 동작 원칙입니다. 화면이 예뻐도 이 규칙을 깨면 출시 검증 실패입니다.

6개 규칙
페어링 격리선택된 아이 또는 페어링된 아이에게만 일정, 메모, 스티커, 위치 요청, 주변소리 요청이 전달됩니다.
아이모드 gate가족 연동 전에는 메모, SOS, 일정 홈을 열지 않고 KID 코드/QR 페어링 화면을 먼저 보여줍니다.
주변소리 target부모가 선택한 아이의 user id를 command payload에 포함하고 다른 아이 기기에는 명령을 보내지 않습니다.
AI 크레딧 scope대화 상한, 기본 크레딧, 추가 크레딧, 요청 상태는 child user scope로 표시합니다.
테마 일치부모모드와 아이모드는 같은 가족 멤버 profile color를 기준으로 테마색을 적용합니다.
선생님 권한선생님은 부모가 수락한 아이와 공유 범위 안의 일정, 참석, 위치만 볼 수 있습니다.
