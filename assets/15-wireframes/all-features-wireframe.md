# 혜니캘린더 전체 기능 Wireframe

생성일: 2026-07-02  
기준: 현재 코드베이스의 `src/App.jsx` 렌더 조건과 주요 화면 컴포넌트

이 문서는 앱의 모든 기능을 설명하기 위한 정보구조 wireframe입니다. 시각 디자인 확정안이 아니라, 누락 없이 화면/기능/예외 상태를 설명하기 위한 기준 산출물입니다.

## 0. 최상위 구조

```text
앱 실행
└─ Splash / 세션 복구 / 기존 역할 확인
   └─ 역할 선택
      ├─ 부모: 로그인/가입/OAuth bridge → 가족 생성 또는 가족 합류 → 부모 홈
      ├─ 아이: 아이모드 진입 → KID 코드/QR 페어링 → 권한 설정 → 아이 홈
      └─ 선생님: 부모와 같은 인증 컨텍스트 → 반 생성/관리 → 선생님 홈
```

### 공통 원칙

- 페어링된 부모와 아이 사이에서만 알림, 채팅, 위치, 주변소리, 테마 색상이 동작한다.
- 부모모드의 `오늘의 메모` 성격 기능은 `아이와 대화하기`로 표현한다.
- 아이모드의 같은 기능은 `부모님에게 이야기하기`로 표현한다.
- 부모 바로가기 11개는 삭제 금지: AI 일정등록, 칭찬스티커, 장소관리, 친구놀이, 응급알림, 주변소리, 구독, 연락처, 피드백, 크레딧, 설정.
- 비연결, 권한 없음, 기기 응답 없음, 구독 gate, AI 크레딧 부족은 정상 화면 상태로 설명해야 한다.

## 9. 격리/정합성 검증 포인트

- 선택된 아이와 다른 아이에게 주변소리, 위치 요청, 스티커, AI 설정이 전달되지 않아야 한다.
- 부모와 아이의 테마색은 같은 가족 멤버 profile color를 기준으로 보여야 한다.
- 아이가 로그인/페어링되지 않은 경우 부모의 주변소리/위치 요청은 예쁜 안내 상태로 끝나야 한다.
- AI 친구 캐릭터는 `C` fallback이 아니라 아이가 선택한 캐릭터로 표시되어야 한다.
- 기존 회원이 재로그인하거나 다른 로그인 방식을 써도 전화번호/OAuth bridge로 기존 계정과 가족 연결이 이어져야 한다.
- 선생님은 부모가 수락한 아이와 공유 범위만 볼 수 있어야 한다.
