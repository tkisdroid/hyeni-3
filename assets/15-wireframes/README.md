# Hyeni Calendar Wireframes

이 폴더는 현재 앱 기능 전체를 설명하기 위한 wireframe 산출물입니다.

- `all-features-wireframe.html`: 브라우저에서 바로 여는 시각 wireframe
- `all-features-wireframe.md`: 문서형 기능/화면 구조
- `all-features-wireframe.mmd`: Mermaid 흐름도
- `feature-inventory.json`: 누락 점검용 기능 인벤토리

검증 기준:

- 부모 바로가기 11개가 모두 포함되어야 합니다.
- 부모/아이/선생님 3개 모드가 모두 포함되어야 합니다.
- 로그인, 가입, OAuth bridge, 가족 생성, 아이 페어링, 권한 흐름이 이어져야 합니다.
- 페어링된 가족 사이에서만 채팅, 알림, 위치, 주변소리, 테마, AI 크레딧이 흐르는 원칙이 표시되어야 합니다.
